## Problem 1: Median of Two Sorted Telemetry Streams

**Topic:** Binary search — median of two sorted arrays

**Google Doc mode:** Solve this one in a plain text editor with no compiling — dry-run by hand.

**Statement:** Two sensor nodes each emit a sorted stream of timestamped readings. The streams are already merged in a gateway, but the gateway stores them as two separate sorted arrays `a` and `b` of sizes `m` and `n`. Return the median value of the combined sorted sequence of all `m + n` readings. The required time complexity is O(log(min(m, n))).

```cpp
double medianOfTwoSortedStreams(const std::vector<int>& a, const std::vector<int>& b);
```

**Example 1:**

```
Input:  a = [100, 200, 300], b = [150, 250]
Output: 200.0
Explanation: The merged sequence is [100, 150, 200, 250, 300]; its median is 200.
```

**Example 2:**

```
Input:  a = [10, 30], b = [20, 40, 50, 60]
Output: 35.0
Explanation: The merged sequence is [10, 20, 30, 40, 50, 60]; its median is (30 + 40) / 2 = 35.
```

**Example 3:**

```
Input:  a = [], b = [7]
Output: 7.0
```

**Constraints:**
- `0 <= a.size(), b.size() <= 1000`
- `a.size() + b.size() >= 1`
- `-10^6 <= a[i], b[i] <= 10^6`
- Each array is sorted in non-decreasing order
- Required time complexity: O(log(min(m, n)))

## Problem 2: Longest Consecutive Packet Sequence

**Topic:** Hash set — longest consecutive sequence in O(n) time

**Statement:** A gateway receives packet sequence numbers in arbitrary order, possibly with duplicates. Given the received sequence numbers, return the length of the longest run of consecutive sequence numbers present in the input. Your algorithm must run in O(n) time — sorting the input (O(n log n)) is not acceptable.

```cpp
int longestConsecutivePackets(const std::vector<int>& packets);
```

**Example 1:**

```
Input:  packets = [100, 4, 200, 1, 3, 2]
Output: 4
Explanation: The longest consecutive run is [1, 2, 3, 4].
```

**Example 2:**

```
Input:  packets = [50, 51, 52, 10, 11, 12, 13]
Output: 4
Explanation: The longest consecutive run is [10, 11, 12, 13].
```

**Example 3:**

```
Input:  packets = []
Output: 0
```

**Example 4:**

```
Input:  packets = [7, 7, 7]
Output: 1
```

**Constraints:**
- `0 <= packets.size() <= 10^5`
- `-10^9 <= packets[i] <= 10^9`
- Required time complexity: O(n)
