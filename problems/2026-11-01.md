## Problem 1: Running Median of Sensor Readings

**Topic:** Heap / priority queue — running median with two heaps

**Statement:**
A temperature sensor emits a continuous stream of integer readings. After each new reading arrives, the monitoring firmware must report the median of all readings seen so far. Implement a class that supports adding a reading and querying the current median in efficient time.

If the count of readings is odd, the median is the middle value. If the count is even, the median is the average of the two middle values (return it as a double).

**Function signature:**
```cpp
class RunningMedian {
public:
    void addReading(int value);
    double median() const;
};
```

**Examples:**
```cpp
RunningMedian m;
m.addReading(5);   // median() -> 5.0
m.addReading(15);  // median() -> 10.0
m.addReading(1);   // median() -> 5.0
m.addReading(3);   // median() -> 4.0
```

**Constraints:**
- `-10^9 <= value <= 10^9`
- `addReading` is called at most `10^5` times
- `median()` is called only when at least one reading has been added
- Each operation should run in O(log n) time

## Problem 2: Duplicate Sensor ID in a Calibration Set (Google Doc mode)

**Topic:** Arrays — Floyd's cycle detection, O(1) extra space

**Mode:** Google Doc mode — solve this one in a plain text editor with no compiling, and dry-run it by hand.

**Statement:**
A calibration rig holds `n + 1` sensor IDs, each an integer in the range `[1, n]`. Exactly one ID appears at least twice (it may appear more than twice); every other ID appears exactly once. The array is read-only — you may not modify it — and you may use only O(1) extra space. Find the duplicated ID without modifying the array.

**Function signature:**
```cpp
int findDuplicate(const std::vector<int>& ids);
```

**Examples:**
```cpp
findDuplicate({1, 3, 4, 2, 2});       // -> 2
findDuplicate({3, 1, 3, 4, 2});       // -> 3
findDuplicate({2, 2, 2, 2, 2});       // -> 2
```

**Constraints:**
- `2 <= ids.size() <= 10^5`
- `1 <= ids[i] <= ids.size() - 1`
- Exactly one value is repeated; all others appear once
- You must not modify the input array
- Your solution must use O(1) extra space (not counting the input) and run in O(n) time
