## Problem 1: Minimum Window Telemetry Substring

**Topic:** Strings / sliding window — smallest substring containing all required codes

**Statement:** A firmware log is a string `log` where each character is a sensor event code. A diagnostic routine needs the shortest contiguous substring of `log` that contains every code in a second string `codes` at least as many times as it appears in `codes`. Return that shortest substring. If no such substring exists, return an empty string. Aim for O(n) time and O(1) extra space (the alphabet is fixed-size).

```cpp
std::string minTelemetryWindow(const std::string& log, const std::string& codes);
```

**Example 1:**

```
Input:  log = "ADOBECODEBANC", codes = "ABC"
Output: "BANC"
Explanation: "BANC" is the shortest substring containing A, B, and C.
```

**Example 2:**

```
Input:  log = "a", codes = "a"
Output: "a"
Explanation: The whole log is the answer.
```

**Example 3:**

```
Input:  log = "a", codes = "aa"
Output: ""
Explanation: The log has only one 'a', but two are required, so no window exists.
```

**Example 4:**

```
Input:  log = "abbcabc", codes = "abc"
Output: "cab"
Explanation: "cab" (indices 3-5) is the shortest substring containing one 'a', one 'b', and one 'c'.
```

**Constraints:**
- `1 <= log.size() <= 10^5`
- `1 <= codes.size() <= log.size()`
- `log` and `codes` consist of English letters (uppercase and lowercase)
- Aim for O(n) time and O(1) extra space

## Problem 2: Word Search in a Firmware Grid

**Topic:** Recursion / backtracking — find a word in a 2D grid

**Google Doc mode:** Solve this one in a plain text editor with no compiling — dry-run by hand.

**Statement:** A firmware image is stored as a 2D grid of characters `board`, where each cell holds one character. A command word `word` is present in the grid if it can be formed by a path of adjacent cells (horizontally or vertically neighboring, never diagonally) such that no cell is used more than once in the path. Return `true` if `word` is present, `false` otherwise. Aim for O(m * n * 3^L) time where L is the length of `word`, and O(L) extra space for the recursion.

```cpp
bool wordSearch(std::vector<std::vector<char>>& board, const std::string& word);
```

**Example 1:**

```
Input:  board = [['A','B','C','E'], ['S','F','C','S'], ['A','D','E','E']], word = "ABCCED"
Output: true
Explanation: The path A(0,0) -> B(0,1) -> C(0,2) -> C(1,2) -> E(2,2) -> D(2,1) spells "ABCCED".
```

**Example 2:**

```
Input:  board = [['A','B','C','E'], ['S','F','C','S'], ['A','D','E','E']], word = "SEE"
Output: true
Explanation: The path S(1,3) -> E(1,2) -> E(2,2) spells "SEE".
```

**Example 3:**

```
Input:  board = [['A','B','C','E'], ['S','F','C','S'], ['A','D','E','E']], word = "ABCB"
Output: false
Explanation: The only 'B' is at (0,1), and after using it once there is no second 'B' to reach.
```

**Example 4:**

```
Input:  board = [['a']], word = "a"
Output: true
Explanation: A single-cell board matches a single-character word.
```

**Constraints:**
- `1 <= board.size() <= 6`
- `1 <= board[0].size() <= 6`
- `1 <= word.size() <= 15`
- `board` and `word` consist of English letters (uppercase and lowercase)
- Aim for O(m * n * 3^L) time and O(L) extra space
