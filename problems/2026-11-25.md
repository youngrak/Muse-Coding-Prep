## Problem 1: Minimum Firmware Update Packages

**Topic:** Dynamic programming — coin change (minimum packages to reach an exact size)

**Statement:** A firmware image of exactly `target` bytes must be assembled from update packages. There are `n` package sizes given in `sizes`, and there is an unlimited supply of each size. Return the minimum number of packages whose sizes sum to exactly `target`. If no combination of packages sums to exactly `target`, return -1.

```cpp
int minUpdatePackages(const std::vector<int>& sizes, int target);
```

**Example 1:**

```
Input:  sizes = [1, 3, 4], target = 6
Output: 2
Explanation: 3 + 3 = 6, using two packages. No single package is 6 bytes,
so 2 is the minimum.
```

**Example 2:**

```
Input:  sizes = [2, 5], target = 3
Output: -1
Explanation: No combination of 2-byte and 5-byte packages sums to 3.
```

**Example 3:**

```
Input:  sizes = [1, 2, 5], target = 11
Output: 3
Explanation: 5 + 5 + 1 = 11, using three packages.
```

**Example 4:**

```
Input:  sizes = [3, 7], target = 0
Output: 0
Explanation: A target of 0 bytes needs no packages at all.
```

**Constraints:**
- `1 <= sizes.size() <= 100`
- `1 <= sizes[i] <= 1000`
- `0 <= target <= 10^4`
- Aim for O(n * target) time and O(target) extra space, where n is the number of package sizes

## Problem 2: Longest Telemetry Substring Without Repeating Codes

**Topic:** Sliding window / hash set — longest substring with all distinct characters

**Google Doc mode:** Solve this one in a plain text editor with no compiling — dry-run by hand.

**Statement:** A telemetry log is a string of single-character sensor codes. Find the length of the longest contiguous substring in which no sensor code appears more than once. Return only the length.

```cpp
int longestUniqueTelemetrySubstring(const std::string& log);
```

**Example 1:**

```
Input:  log = "ABCADEB"
Output: 5
Explanation: The longest substring with all distinct codes is "BCADE"
(length 5). The substring starting at the first 'A' is cut short when 'A'
appears again, and the final 'B' repeats the earlier 'B'.
```

**Example 2:**

```
Input:  log = "AAAA"
Output: 1
Explanation: Every code is the same, so no substring longer than 1 has all
distinct codes.
```

**Example 3:**

```
Input:  log = "ABCDEF"
Output: 6
Explanation: All codes are already distinct, so the whole log qualifies.
```

**Example 4:**

```
Input:  log = ""
Output: 0
Explanation: An empty log has no substring.
```

**Constraints:**
- `0 <= log.size() <= 10^5`
- Each code is a printable ASCII character
- Aim for O(n) time and O(min(n, alphabet size)) extra space, where n is the length of the log
