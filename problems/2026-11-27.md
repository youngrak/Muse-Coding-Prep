## Problem 1: Sensor Charging Circuit

**Topic:** Greedy — circular route with fuel/charging stations

**Statement:** A field technician must visit `n` charging stations arranged in a circle to service a fleet of sensors. Station `i` provides `charge[i]` units of energy, and driving from station `i` to the next station `(i + 1) % n` consumes `cost[i]` units of energy. The technician starts with an empty battery at one station of their choice, collects that station's charge, and then drives station by station around the circle. Return the index of a starting station from which the technician can complete the full circle, or `-1` if no such starting station exists. If a solution exists, it is guaranteed to be unique.

```cpp
int chargingCircuitStart(const std::vector<int>& charge, const std::vector<int>& cost);
```

**Example 1:**

```
Input:  charge = [1, 2, 3, 4, 5], cost = [3, 4, 5, 1, 2]
Output: 3
Explanation: Start at station 3. Battery after each leg:
3 -> 4: 4 - 1 = 3; 4 -> 0: 3 + 5 - 2 = 6;
0 -> 1: 6 + 1 - 3 = 4; 1 -> 2: 4 + 2 - 4 = 2;
2 -> 3: 2 + 3 - 5 = 0. The battery never drops below zero, so
station 3 completes the circuit.
```

**Example 2:**

```
Input:  charge = [2, 3, 4], cost = [3, 4, 3]
Output: -1
Explanation: Total charge (9) is less than total cost (10), so no
starting station can complete the circuit.
```

**Example 3:**

```
Input:  charge = [5, 1, 2, 3, 4], cost = [4, 4, 1, 5, 1]
Output: 4
Explanation: Start at station 4. Battery after each leg:
4 -> 0: 4 - 1 = 3; 0 -> 1: 3 + 5 - 4 = 4;
1 -> 2: 4 + 1 - 4 = 1; 2 -> 3: 1 + 2 - 1 = 2;
3 -> 4: 2 + 3 - 5 = 0. The battery never drops below zero.
```

**Example 4:**

```
Input:  charge = [4], cost = [4]
Output: 0
Explanation: A single station with enough charge to reach itself
completes the circuit.
```

**Constraints:**
- `1 <= charge.size() == cost.size() <= 10^5`
- `0 <= charge[i], cost[i] <= 10^4`
- Aim for O(n) time and O(1) extra space

## Problem 2: Fault Propagation in a Sensor Grid

**Topic:** Graphs — multi-source BFS on a grid (time for a fault to spread)

**Google Doc mode:** Solve this one in a plain text editor with no compiling — dry-run by hand.

**Statement:** A sensor field is a grid of `m` rows and `n` columns. Each cell holds one of three states: `0` means the cell is empty (no sensor), `1` means the cell holds a healthy sensor, and `2` means the cell holds a faulty sensor. Every minute, each faulty sensor spreads its fault to its healthy sensors in the four adjacent cells (up, down, left, right). Empty cells never become faulty and never spread a fault. Return the number of minutes until every sensor in the grid is faulty. If some healthy sensor can never become faulty, return `-1`. If there are no healthy sensors to begin with, return `0`.

```cpp
int faultPropagationMinutes(std::vector<std::vector<int>>& grid);
```

**Example 1:**

```
Input:  grid = [[2, 1, 1],
                [1, 1, 0],
                [0, 1, 1]]
Output: 4
Explanation: Minute 1: the fault spreads to (0, 1) and (1, 0).
Minute 2: it spreads to (0, 2) and (1, 1). Minute 3: it spreads
to (2, 1). Minute 4: it spreads to (2, 2). All sensors are
faulty after 4 minutes.
```

**Example 2:**

```
Input:  grid = [[2, 1, 1],
                [0, 1, 1],
                [1, 0, 1]]
Output: -1
Explanation: The healthy sensor at (2, 0) is cut off by empty
cells and can never become faulty.
```

**Example 3:**

```
Input:  grid = [[0, 2]]
Output: 0
Explanation: There are no healthy sensors, so no time is needed.
```

**Example 4:**

```
Input:  grid = [[1, 1],
                [1, 2]]
Output: 2
Explanation: Minute 1: the fault spreads to (0, 1) and (1, 0).
Minute 2: it spreads to (0, 0). All sensors are faulty after
2 minutes.
```

**Constraints:**
- `1 <= m, n <= 10`
- `grid[i][j]` is `0`, `1`, or `2`
- Aim for O(m * n) time and O(m * n) extra space
