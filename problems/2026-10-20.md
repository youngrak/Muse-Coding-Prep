## Problem 1 - Search in a Rotated Calibration Table

Topic: binary search

A sensor stores its calibration values in a strictly increasing array. Due to a circular-buffer write offset, the array was rotated at an unknown pivot point, so it now looks like two sorted runs back to back. Given the rotated array and a target value, return the index of the target, or -1 if it is not present.

Your solution must run in O(log n) time.

```cpp
int searchRotated(const std::vector<int>& values, int target)
```

Example 1:

```
values = [15, 18, 21, 3, 6, 9, 12], target = 6  ->  4
```

Example 2:

```
values = [15, 18, 21, 3, 6, 9, 12], target = 20  ->  -1
```

Example 3:

```
values = [5], target = 5  ->  0
```

Constraints:

- 1 <= values.size() <= 100,000
- All values are distinct.
- The original array was strictly increasing before rotation (rotation by 0 is possible).
- -10^9 <= values[i], target <= 10^9

## Problem 2 - First Unique Telemetry Code

Topic: hash map

A device uploaded a batch of telemetry event codes, in order. Find the first code that appears exactly once in the batch. Return that code, or an empty string if every code repeats.

```cpp
std::string firstUniqueCode(const std::vector<std::string>& codes)
```

Example 1:

```
codes = ["TEMP", "IMU", "TEMP", "GPS", "IMU", "GPS", "MODEM"]  ->  "MODEM"
```

Example 2:

```
codes = ["GPS", "GPS"]  ->  ""
```

Example 3:

```
codes = ["IMU"]  ->  "IMU"
```

Constraints:

- 1 <= codes.size() <= 100,000
- Each code is a non-empty string of uppercase letters and digits, length <= 16.
- Expected time complexity O(n).
