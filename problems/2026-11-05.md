## Problem 1: Time-Based Sensor Reading Store

**Topic:** Design — hash map + binary search

**Statement:**
Design a class `SensorReadingStore` that keeps timestamped readings from many sensors. `set(sensorId, value, timestamp)` records a reading for a sensor at the given timestamp. `get(sensorId, timestamp)` returns the value of the most recent reading for that sensor at or before the given timestamp, or -1 if the sensor has no reading at or before that timestamp. Timestamps passed to `set` for the same sensor are strictly increasing.

**Function signature:**
```cpp
class SensorReadingStore {
public:
    void set(const std::string& sensorId, int value, int timestamp);
    int get(const std::string& sensorId, int timestamp);
};
```

**Example:**
```cpp
SensorReadingStore store;
store.set("temp", 21, 1);
store.set("temp", 23, 5);
store.get("temp", 3);       // returns 21
store.get("temp", 5);       // returns 23
store.get("temp", 0);       // returns -1
store.get("pressure", 10);  // returns -1
```

**Constraints:**
- `1 <= sensorId.length() <= 20`
- `-1000 <= value <= 1000`
- `1 <= timestamp <= 10^9`
- Timestamps in `set` calls for the same sensor are strictly increasing
- At most `10^5` total calls to `set` and `get`

## Problem 2: Firmware Task Scheduling with Cooldown

**Topic:** Heap / greedy — task scheduling with a cooldown interval

**Mode:** Google Doc mode — solve in a plain text editor with no compiling; dry-run by hand.

**Statement:**
A firmware update runs a sequence of jobs, each identified by an uppercase letter (e.g. `'A'` = flash write, `'B'` = verify). The same job type must be separated by at least `n` intervals between two executions (other jobs or idle slots count toward the gap). Each interval executes exactly one job or stays idle. Return the minimum total number of intervals needed to run all the jobs.

**Function signature:**
```cpp
int leastInterval(std::vector<char>& tasks, int n);
```

**Example:**
```cpp
leastInterval({'A','A','A','B','B','B'}, 2);                          // returns 8
leastInterval({'A','A','A','B','B','B'}, 0);                          // returns 6
leastInterval({'A','A','A','A','A','A','B','C','D','E','F','G'}, 2);  // returns 16
```

**Constraints:**
- `1 <= tasks.size() <= 10^4`
- Each task is an uppercase English letter
- `0 <= n <= 100`
