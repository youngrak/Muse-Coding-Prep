## Problem 1: Firmware Update Propagation

**Topic:** Trees/graphs — BFS traversal

A gateway device (node 0) rolls out a firmware update across a fleet of devices. The fleet is connected as an undirected graph given by an adjacency list. Each minute, every device that already has the update forwards it to all of its direct neighbors that do not have it yet. Return the number of minutes until every device has the update, or -1 if some device can never be reached from the gateway.

**Required signature:**

```cpp
int propagationTime(int n, const std::vector<std::vector<int>>& adj);
```

**Examples:**

```
n = 5, adj = [[1,2],[0,3],[0],[1,4],[3]]  ->  3
n = 4, adj = [[1,2,3],[0],[0],[0]]        ->  1
n = 4, adj = [[1],[0],[3],[2]]            ->  -1
```

**Constraints:**

- 1 <= n <= 10^5
- `adj[i]` lists the neighbors of node `i`; each undirected edge appears in both directions
- Total adjacency entries <= 2 * 10^5
- Aim for O(n + edges) time and O(n) space

## Problem 2: Sensor Calibration Combinations

**Topic:** Recursion/backtracking — combination sum

A sensor needs a calibration offset that sums exactly to a `target` value. You are given distinct candidate offsets. Find all combinations of candidates (each candidate used at most once, order within a combination does not matter) that sum to `target`. Return every valid combination; the order of the combinations does not matter.

**[Google Doc mode: solve in a plain text editor with no compiling; dry-run your code by hand.]**

**Required signature:**

```cpp
std::vector<std::vector<int>> calibrationCombinations(const std::vector<int>& candidates, int target);
```

**Examples:**

```
candidates = [2, 3, 5, 7], target = 7  ->  [[2, 5], [7]]
candidates = [1, 2, 3],     target = 3  ->  [[1, 2], [3]]
candidates = [2, 4],        target = 7  ->  []
```

**Constraints:**

- 1 <= candidates.size() <= 20
- Candidates are distinct, 1 <= candidates[i] <= 50
- 1 <= target <= 200
- Do not return duplicate combinations
