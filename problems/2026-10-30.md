## Problem 1: Sensor Threshold Tree Validation

**Topic:** Trees — binary search tree validation

**Google Doc mode:** Solve this problem in a plain text editor with no compiling, and dry-run your code by hand.

**Statement:** A firmware configuration stores sensor alarm thresholds in a binary tree: each node holds a threshold value, and the tree is supposed to be a valid binary search tree, meaning every value in a node's left subtree is strictly smaller than the node's value, and every value in its right subtree is strictly larger. A recent config migration may have corrupted the ordering. Given the root of the tree, determine whether it is a valid binary search tree. Note that checking only each node's immediate children is not enough — a value deep in a subtree must still respect every ancestor's bound.

**Implement the function below:**

```cpp
#include <vector>
using namespace std;

struct TreeNode {
    int val;
    TreeNode* left;
    TreeNode* right;
    TreeNode(int x) : val(x), left(nullptr), right(nullptr) {}
};

bool isValidThresholdTree(TreeNode* root);
```

**Examples:**

```
Input:  root = [10, 5, 15, 2, 7, 12, 20]   (level order, null = missing child)
Output: true
```

```
Input:  root = [10, 5, 15, 2, 7, null, 20, null, null, 6, 8]
        (the node with value 6 sits in the left subtree of 10, below the node 7)
Output: false
```

```
Input:  root = [10, 10, 20]
Output: false   (duplicate values are not allowed)
```

**Constraints:**

- The number of nodes in the tree is in the range [0, 10000].
- -2^31 <= TreeNode.val <= 2^31 - 1
- An empty tree (root == nullptr) is valid.
- You may use O(h) extra space where h is the tree height, but the solution must run in O(n) time.

## Problem 2: Peak Power Draw Window

**Topic:** Arrays — maximum subarray sum (Kadane's algorithm)

**Statement:** A wearable sensor logs its power draw once per second, relative to a baseline: positive values mean extra draw, negative values mean the device was charging or idle below baseline. Given the sequence of per-second readings, find the contiguous window with the largest total power draw. The window must contain at least one reading, even if every reading is negative (in that case the answer is the least negative single reading).

**Implement the function below:**

```cpp
#include <vector>
using namespace std;

int maxPowerDrawWindow(const vector<int>& readings);
```

**Examples:**

```
Input:  readings = [-2, 1, -3, 4, -1, 2, 1, -5, 4]
Output: 6   (the window [4, -1, 2, 1] sums to 6)
```

```
Input:  readings = [5, 4, -1, 7, 8]
Output: 23  (the whole array)
```

```
Input:  readings = [-3, -1, -2]
Output: -1  (the single reading -1)
```

**Constraints:**

- 1 <= readings.size() <= 100000
- -10000 <= readings[i] <= 10000
- The answer fits in a 32-bit signed integer.
- An O(n) time, O(1) extra space solution is expected; state the time and space complexity of your approach.
