## Problem 1: Strongly Connected Sensor Clusters [Google Doc mode]

**Topic:** Graphs: strongly connected components (Kosaraju's or Tarjan's algorithm)

A sensor mesh has n devices numbered 0 to n-1. A directed link (u, v) means device u can send telemetry directly to device v. Two devices belong to the same cluster if each can reach the other through one or more directed links (a single device alone is a cluster of one). Return every cluster in the mesh.

```cpp
std::vector<std::vector<int>> stronglyConnectedComponents(int n, const std::vector<std::pair<int, int>>& links);
```

```
Input: n = 5, links = [(0, 1), (1, 2), (2, 0), (1, 3), (3, 4)]
Output: [[0, 1, 2], [3], [4]]
Explanation: Devices 0, 1, and 2 can all reach each other, while 3 and 4 cannot reach back.
```

**Constraints:**
- 1 <= n <= 100,000
- 0 <= links.size() <= 200,000; each link (u, v) satisfies 0 <= u, v < n
- Return each cluster sorted in ascending order, and the clusters sorted by their smallest member.
- Your algorithm should run in O(n + m) time where m is the number of links.

## Problem 2: Minimum Firmware Patch Set

**Topic:** Dynamic programming: minimum coins / unbounded knapsack

A firmware image must advance by exactly targetDelta versions. You have patch packages of the sizes listed in patchSizes, and you may apply any patch size any number of times. Return the minimum number of patches whose sizes sum to exactly targetDelta, or -1 if no combination reaches it exactly.

```cpp
int minPatches(const std::vector<int>& patchSizes, int targetDelta);
```

```
Input: patchSizes = [1, 3, 4], targetDelta = 6
Output: 2
Explanation: 3 + 3 = 6 uses two patches; no single-patch solution exists.

Input: patchSizes = [2, 5], targetDelta = 3
Output: -1
Explanation: No combination of 2s and 5s sums to 3.
```

**Constraints:**
- 1 <= patchSizes.size() <= 100; each patch size is a positive integer
- 0 <= targetDelta <= 10,000
- Patch sizes may contain duplicates; you may use each size any number of times.
- Aim for O(targetDelta * patchSizes.size()) time and O(targetDelta) space.
