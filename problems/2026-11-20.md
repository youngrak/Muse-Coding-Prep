## Problem 1: Product of Sensor Readings Except Self

**Topic:** Arrays — prefix/suffix products, O(n) time with O(1) extra space

**Google Doc mode:** Solve this one in a plain text editor with no compiling — dry-run by hand.

**Statement:** A calibration sensor reports a sequence of gain readings. For each reading, compute the product of every *other* reading in the sequence — the reading at that position itself is excluded. Return the results in the same order as the input. You may not use division, and the product of any prefix of the input is guaranteed to fit in a 32-bit signed integer. Aim for O(n) time and O(1) extra space not counting the output array.

```cpp
std::vector<int> productExceptSelf(const std::vector<int>& readings);
```

**Example 1:**

```
Input:  readings = [1, 2, 3, 4]
Output: [24, 12, 8, 6]
Explanation: 2*3*4 = 24, 1*3*4 = 12, 1*2*4 = 8, 1*2*3 = 6.
```

**Example 2:**

```
Input:  readings = [-1, 1, 0, -3, 3]
Output: [0, 0, 9, 0, 0]
Explanation: The single zero makes every product except the zero's own position equal to 0; the zero's own product is (-1)*1*(-3)*3 = 9.
```

**Example 3:**

```
Input:  readings = [2, 0]
Output: [0, 2]
Explanation: With only one zero, the zero's position gets the product of the rest (2) and the other position gets 0.
```

**Example 4:**

```
Input:  readings = [5]
Output: [1]
Explanation: There are no other readings, so the empty product is 1.
```

**Constraints:**
- `1 <= readings.size() <= 10^5`
- `-30 <= readings[i] <= 30`
- The product of any prefix of `readings` fits in a 32-bit signed integer
- Do not use division
- Aim for O(n) time and O(1) extra space not counting the output

## Problem 2: Kth Smallest Reading in a Sorted Sensor Matrix

**Topic:** Heap / binary search — kth smallest in a row- and column-sorted matrix

**Statement:** A sensor grid records readings in an `n x n` matrix where every row is sorted in ascending order from left to right and every column is sorted in ascending order from top to bottom. Given the matrix and an integer `k` (1-indexed), return the kth smallest reading in the whole matrix. A straightforward sort of all `n^2` readings is too slow for a large grid, so aim for something better — either a heap-based approach or a binary search over the value range.

```cpp
int kthSmallest(const std::vector<std::vector<int>>& matrix, int k);
```

**Example 1:**

```
Input:  matrix = [[1, 5, 9], [10, 11, 13], [12, 13, 15]], k = 8
Output: 13
Explanation: The readings in sorted order are [1, 5, 9, 10, 11, 12, 13, 13, 15]; the 8th smallest is 13.
```

**Example 2:**

```
Input:  matrix = [[-5]], k = 1
Output: -5
Explanation: A 1x1 matrix has only one reading.
```

**Example 3:**

```
Input:  matrix = [[1, 2], [1, 3]], k = 2
Output: 1
Explanation: Duplicate readings count separately; the sorted order is [1, 1, 2, 3], so the 2nd smallest is 1.
```

**Example 4:**

```
Input:  matrix = [[1, 2], [1, 3]], k = 3
Output: 2
Explanation: Duplicate readings count separately; the sorted order is [1, 1, 2, 3].
```

**Constraints:**
- `n == matrix.size() == matrix[i].size()`
- `1 <= n <= 300`
- `-10^9 <= matrix[i][j] <= 10^9`
- `1 <= k <= n * n`
- All rows and all columns are sorted in non-decreasing order
- Aim for better than O(n^2 log(n^2)) time
