## Problem 1: Longest Increasing Calibration Sequence

**Topic:** Dynamic programming / binary search — longest increasing subsequence

**Google Doc mode:** Solve this one in a plain text editor with no compiling — dry-run by hand.

**Statement:** A sensor logs calibration readings over time as an integer array `readings`, where `readings[i]` is the reading at time `i`. A calibration sequence is a subsequence of `readings` (not necessarily contiguous) whose values are strictly increasing. Return the length of the longest such sequence. Aim for O(n log n) time and O(n) extra space.

```cpp
int longestIncreasingCalibration(const std::vector<int>& readings);
```

**Example 1:**

```
Input:  readings = [10, 9, 2, 5, 3, 7, 101, 18]
Output: 4
Explanation: The longest strictly increasing subsequence is [2, 3, 7, 18] (or [2, 5, 7, 101]), of length 4.
```

**Example 2:**

```
Input:  readings = [0, 1, 0, 3, 2, 3]
Output: 4
Explanation: The longest strictly increasing subsequence is [0, 1, 2, 3], of length 4.
```

**Example 3:**

```
Input:  readings = [7, 7, 7, 7, 7, 7, 7]
Output: 1
Explanation: All readings are equal, so no strictly increasing subsequence longer than 1 exists.
```

**Example 4:**

```
Input:  readings = []
Output: 0
Explanation: With no readings there is no sequence at all.
```

**Constraints:**
- `0 <= readings.size() <= 2500`
- `-10^4 <= readings[i] <= 10^4`
- Aim for O(n log n) time and O(n) extra space

## Problem 2: Sensor Energy Anomaly Windows

**Topic:** Hash map / prefix sums — count subarrays with a target sum

**Statement:** A power monitor records the energy drawn by a sensor node in each one-second interval as an integer array `energy`, where `energy[i]` may be positive (draw) or negative (regenerative feedback). An anomaly window is a contiguous subarray whose total energy equals exactly `target`. Return the number of anomaly windows. Aim for O(n) time and O(n) extra space.

```cpp
int countAnomalyWindows(const std::vector<int>& energy, int target);
```

**Example 1:**

```
Input:  energy = [1, 1, 1], target = 2
Output: 2
Explanation: The subarrays [1, 1] (indices 0-1) and [1, 1] (indices 1-2) both sum to 2.
```

**Example 2:**

```
Input:  energy = [1, 2, 3], target = 3
Output: 2
Explanation: The subarrays [1, 2] and [3] both sum to 3.
```

**Example 3:**

```
Input:  energy = [1, -1, 0], target = 0
Output: 3
Explanation: The subarrays [1, -1], [0], and [1, -1, 0] all sum to 0.
```

**Example 4:**

```
Input:  energy = [3, 4, 7, 2, -3, 1, 4, 2], target = 7
Output: 4
Explanation: The four windows are [3, 4], [7], [7, 2, -3, 1], and [1, 4, 2].
```

**Constraints:**
- `1 <= energy.size() <= 2 * 10^4`
- `-1000 <= energy[i] <= 1000`
- `-10^7 <= target <= 10^7`
- Aim for O(n) time and O(n) extra space
