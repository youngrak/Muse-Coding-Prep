## Problem 1: Longest Palindromic Telemetry Frame

**Topic:** Strings — two pointers (expand around center)

**Google Doc mode:** Solve this one in a plain text editor with no compiling — dry-run by hand.

**Statement:** A telemetry frame arrives as a string of lowercase letters and digits. A "palindromic frame" is a contiguous substring that reads the same forwards and backwards. Given the frame string `s`, return the longest palindromic substring. If there are several palindromes of the same maximum length, return any one of them.

```cpp
std::string longestPalindromicFrame(const std::string& s);
```

**Example 1:**

```
Input:  s = "babad"
Output: "bab"
Explanation: "aba" is also a valid answer.
```

**Example 2:**

```
Input:  s = "cbbd"
Output: "bb"
```

**Example 3:**

```
Input:  s = "0a1b1a0"
Output: "0a1b1a0"
```

**Constraints:**
- `1 <= s.length() <= 1000`
- `s` consists of lowercase English letters and digits.

## Problem 2: Top-K Most Frequent Sensor Faults

**Topic:** Heap / priority queue — top-k frequent elements (hash map + heap)

**Statement:** A fleet of sensors reports fault codes as integers over the course of a day. Given the list of reported fault codes and an integer `k`, return the `k` most frequent fault codes, in any order. You may assume `k` is valid (it is at most the number of distinct fault codes).

```cpp
std::vector<int> topKFrequentFaults(const std::vector<int>& faultCodes, int k);
```

**Example 1:**

```
Input:  faultCodes = [1, 1, 1, 2, 2, 3], k = 2
Output: [1, 2]
```

**Example 2:**

```
Input:  faultCodes = [7], k = 1
Output: [7]
```

**Example 3:**

```
Input:  faultCodes = [5, 5, 4, 4, 4, 3, 3, 3, 3], k = 2
Output: [3, 4]
```

**Constraints:**
- `1 <= faultCodes.size() <= 10^5`
- `-10^4 <= faultCodes[i] <= 10^4`
- `1 <= k <= number of distinct fault codes`
