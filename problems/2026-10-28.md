## Problem 1: Merged Telemetry Stream

**Topic:** Heap / priority queue — k-way merge

**Statement:** A gateway collects timestamped readings from `k` sensors. Each sensor's readings arrive already sorted in non-decreasing timestamp order. Merge all `k` streams into a single sorted list of timestamps. Readings with equal timestamps may appear in any relative order, but every reading must appear exactly once.

**Function signature:**

```cpp
#include <vector>
using namespace std;

vector<int> mergeTelemetryStreams(const vector<vector<int>>& streams);
```

**Example:**

```
Input:  streams = [[1, 4, 5], [1, 3, 4], [2, 6]]
Output: [1, 1, 2, 3, 4, 4, 5, 6]
```

```
Input:  streams = [[], [2, 2], []]
Output: [2, 2]
```

**Constraints:**
- 0 <= k <= 1000, where k is the number of streams
- 0 <= total number of readings across all streams <= 100000
- 0 <= timestamp <= 1000000000
- Each individual stream is sorted in non-decreasing order
- An empty stream contributes no readings; all streams may be empty

## Problem 2: Shortest Path in a Sensor Mesh

**Topic:** Graphs — Dijkstra's shortest path with path reconstruction

**Mode:** Google Doc mode — solve in a plain text editor with no compiling, and dry-run by hand.

**Statement:** A sensor mesh has `n` nodes numbered `0` to `n - 1`, connected by undirected links. Each link is given as `[u, v, latency]`, where `latency` is the positive transmission delay between nodes `u` and `v`. Find a path from `source` to `target` with the minimum total latency. Return the nodes on that path in order, starting with `source` and ending with `target`. If no path exists, return an empty vector. If several paths tie for minimum latency, any one of them is acceptable.

**Function signature:**

```cpp
#include <vector>
using namespace std;

vector<int> shortestPath(int n, const vector<vector<int>>& links, int source, int target);
```

**Example:**

```
Input:  n = 5, links = [[0, 1, 4], [0, 2, 1], [2, 1, 2], [1, 3, 1], [2, 3, 5], [3, 4, 3]],
        source = 0, target = 4
Output: [0, 2, 1, 3, 4]
```

```
Input:  n = 3, links = [[0, 1, 2]], source = 0, target = 2
Output: []
```

**Constraints:**
- 1 <= n <= 10000
- 0 <= number of links <= 100000
- Each link is [u, v, latency] with 0 <= u, v < n, u != v, and 1 <= latency <= 10000
- Links are undirected: a link [u, v, latency] can be traversed in either direction
- 0 <= source, target < n
- If source == target, return a vector containing just that node
